# Sahar Beauty — אתר תדמית והזמנות

אב־טיפוס רספונסיבי בשלוש שפות: English, العربية, עברית. שם המותג מוצג באנגלית. המראה משתמש בפלטת הקרם, סנד, טוסט, מוקה וקקאו מלוחות ההשראה שצורפו.

## מה כלול באב־טיפוס

- עמודי אודות, שירותים, גלריה, קורסים עתידיים, המלצה לדוגמה ויצירת קשר.
- טופס תור שבו הלקוחה בוחרת מתי תרצה להיות מוכנה; שעת תחילת האיפור מחושבת לפי משך השירות.
- ניהול שירותים בדאשבורד: הוספה, עריכת שמות ותיאורים בשלוש שפות, קביעת משך, והסרה או החזרה לאתר. שירות שהוסר נשאר בהיסטוריית התורים.
- באתר הציבורי רשימת השירותים נפתחת ונסגרת, וטופס ההזמנה מציג רק שירותים פעילים.
- עורך טקסטים בדאשבורד מציג את האתר בשפה נבחרת ומאפשר לערוך טקסטים ישירות בתצוגה, ולשמור אותם לאתר בשלוש השפות.
- אפשרויות תשלום בטופס: Bit, העברה בנקאית ומזומן. כרטיס אשראי ו־Apple Pay אינם מוצגים.
- בתשלום Bit, מספר הטלפון 0538800769 מוצג עם כפתור העתקה, והלקוחה מתבקשת לצרף צילום מסך.
- הצגת עירבון של 100 ₪ ויתרה ליום התור.
- ממשק הניהול מופרד מהאתר הציבורי. הכניסה הרגילה מיועדת לשם משתמש וסיסמה; כתובת בעלת העסק נשמרת בהגדרה פרטית ב‑Supabase, ופונקציית Edge מתווכת בין שם המשתמש לבין התחברות Supabase בלי לחשוף את האימייל בקוד הציבורי. לאחר הכניסה ניתן להגדיר סיסמה.
- מעבר שפה ויישור RTL לעברית ולערבית.

## צפייה והתקנה

פתחו את `index.html` בדפדפן. אפשר להוסיף את דף הניהול למסך הבית מתוך הדפדפן; במכשירים נתמכים מופיע חלון התקנה, ובמכשירי iPhone/iPad יש לבחור בתפריט השיתוף „הוספה למסך הבית”.

## חשוב לפני פרסום

פרויקט Supabase, הטבלאות וכללי RLS הוגדרו. כדי להפעיל כניסה בשם משתמש וסיסמה יש לפרוס את `supabase/functions/admin-login` ולהגדיר ב‑Supabase Secrets את `ADMIN_LOGIN_EMAIL`, `ADMIN_LOGIN_USERNAME` (ברירת מחדל: `sahar`) ו־`PUBLIC_API_KEY`; ‏`SUPABASE_URL` מוגדר אוטומטית ב‑Supabase. האימייל נשאר בסודות שרת ובהגדרות הפרטיות, לא בקובץ ציבורי. בכניסה הראשונה או בשחזור נשלח קישור חד־פעמי לאימייל בעלת העסק; אחרי כניסה יש להגדיר סיסמה בדאשבורד. אין להכניס פרטי לקוחות לפני השלמת חיבור ההתחברות ובדיקתו. עדיין אין חיבור אוטומטי אמיתי ל־Bit, מניעת התנגשות בין תורים, הודעות אישור או תזכורות. כפתור Bit משתמש בקישור עסקי שהתקבל מספק התשלום; מספר טלפון לבדו אינו תחליף לקישור התשלום של העסק.

תמונות הגלריה והביקורת הן להמחשה ויש להחליף אותן בעבודות ובחוות דעת אמיתיות של Sahar Beauty. יש לעדכן גם קישורי WhatsApp ו־Instagram ופרטי קשר.

## קובצי ניהול

- `admin.html` — מסך ניהול נפרד, שאינו מקושר מהאתר הרגיל.
- `admin-config.js` — כתובת פרויקט Supabase ומפתח publishable ציבורי בלבד. כתובת בעלת העסק נשמרת ב־Supabase ולא נחשפת בקבצים הציבוריים. אין להוסיף כאן service-role key.
- `supabase-setup.sql` — טבלאות, הרשאות RLS ו־bucket פרטי לצילומי תשלום.
- `services-migration.sql` — יש להריץ פעם אחת ב‑Supabase SQL Editor לפני פרסום הקבצים המעודכנים; הוא מוסיף את קטלוג השירותים והרשאותיו.
- `site-texts-migration.sql` — יש להריץ פעם אחת ב‑Supabase SQL Editor כדי לאפשר שמירה של טקסטים ערוכים באתר.
- `supabase/functions/admin-login` — תיווך שרת מאובטח לכניסה בשם משתמש וסיסמה ולהגדרה ראשונית.
- `admin.webmanifest` ואייקוני `admin-icon-*` — התקנת דף הניהול במסך הבית.
