# Sahar Beauty — אתר תדמית והזמנות

אב־טיפוס רספונסיבי בשלוש שפות: English, العربية, עברית. שם המותג מוצג באנגלית. המראה משתמש בפלטת הקרם, סנד, טוסט, מוקה וקקאו מלוחות ההשראה שצורפו.

## מה כלול באב־טיפוס

- עמודי אודות, שירותים, גלריה, קורסים עתידיים, המלצה לדוגמה ויצירת קשר.
- טופס תור שבו הלקוחה בוחרת מתי תרצה להיות מוכנה; שעת תחילת האיפור מחושבת לפי משך השירות.
- אפשרויות תשלום בטופס: Bit, העברה בנקאית ומזומן. כרטיס אשראי ו־Apple Pay אינם מוצגים.
- בתשלום Bit, מספר הטלפון 0538800769 מוצג עם כפתור העתקה, והלקוחה מתבקשת לצרף צילום מסך.
- הצגת עירבון של 100 ₪ ויתרה ליום התור.
- ממשק הניהול הופרד מהעמוד הציבורי ומופיע בכתובת `/admin.html`; אין באתר הציבורי קישור אליו.
- ממשק הניהול כולל מסך התחברות והגדרות שירותים ותשלום, אך עדיין לא פעיל עד לחיבור לפרויקט Supabase.
- מעבר שפה ויישור RTL לעברית ולערבית.

## צפייה

פתחו את `index.html` בדפדפן. אין צורך בהתקנה.

## חשוב לפני פרסום

זהו אב־טיפוס. טופס ההזמנה עדיין אינו מחובר לאחסון משותף, וממשק הניהול חסום עד להגדרת פרטי Supabase בקובץ `admin-config.js` ולהרצת `supabase-setup.sql`. לאחר חיבורו, Supabase Auth יגן על הדאשבורד, כללי RLS יגבילו גישה לחשבונות של בעלת העסק, וצילומי Bit יישמרו ב־bucket פרטי. אין להכניס פרטי לקוחות או להשתמש באתר לניהול תורים אמיתי לפני סיום החיבור ובדיקתו. עדיין אין חיבור אמיתי ל־Bit, מניעת התנגשות בין תורים, הודעות אישור או תזכורות. כפתור Bit משתמש בקישור עסקי שהתקבל מספק התשלום; מספר טלפון לבדו אינו תחליף לקישור התשלום של העסק.

תמונות הגלריה והביקורת הן להמחשה ויש להחליף אותן בעבודות ובחוות דעת אמיתיות של Sahar Beauty. יש לעדכן גם קישורי WhatsApp ו־Instagram ופרטי קשר.

## קובצי ניהול

- `admin.html` — מסך ניהול נפרד, שאינו מקושר מהאתר הרגיל.
- `admin-config.js` — כתובת פרויקט Supabase, publishable key והאימייל של בעלת העסק. אין להוסיף כאן service-role key.
- `supabase-setup.sql` — טבלאות, הרשאות RLS ו־bucket פרטי לצילומי תשלום.
